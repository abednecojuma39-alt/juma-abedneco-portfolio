About Me

I'm Juma Abedneco, a Computer Science student at The Kitale National Polytechnic. I'm drawn to how software, data, and networks fit together — from the code that runs an application, to the database behind it, to the network that connects it all — and I enjoy learning new technologies and building practical solutions to real-world problems.

My interests span software development, web development, databases, and networking. My goal is to grow into a skilled, reliable software developer who can take a problem from idea to working solution.

What I Do

  • Programming

    Writing clean, working code — mainly in Java — to solve practical problems.

  • Web Development

    Building responsive websites and interfaces with HTML, CSS and JavaScript.

  • Database Management

    Designing and querying relational databases with MySQL and Microsoft Access.

  • IT & Networking

    Setting up, maintaining and troubleshooting computer networks and hardware.
